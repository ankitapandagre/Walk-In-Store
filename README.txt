WALK-IN STORE — BEGINNER WEBSITE PROTOTYPE

FILES
- index.html: page structure and content
- style.css: colors, layout, responsive styling
- script.js: sample listings, search, filters, demo add-book form

HOW TO RUN
1. Download and extract the ZIP.
2. Open the folder in VS Code.
3. Double-click index.html to open it in a browser.
   Optional: use VS Code Live Server.

WHAT WORKS
- Search books by title, author, or store.
- Filter by area.
- Show available books only.
- Open a Google Maps search for a sample store address.
- Preview the shopkeeper add-book form and add a temporary listing.

IMPORTANT
All store names, prices, stock, and distances are sample data. The add-book form changes this page only and will reset on refresh. There is no real database, login, live GPS, or embedded live map yet. Confirm actual availability with a shop before visiting.

BEGINNER EDITS
1. Change sample books in the books array in script.js.
2. Add another book object to that array.
3. Change colors near the top of style.css in :root.
4. Edit headings and page text in index.html.
